# Kiroween Page Builder

A planned Halloween event page builder for the **Costume Contest** category of Kiroween 2026.

**Status: planning.** This repository was created on October 31, 2026. No runnable application has been implemented yet.

## Project plan

Build an event page builder with a polished Halloween visual theme:

- Arrange page components with drag-and-drop editing.
- Preview pages on desktop and mobile layouts.
- Publish event pages for visitors.

## Development scope and existing work

The plan is to build this new application with Kiro during the hackathon submission period.

The existing `udao-next` project predates the hackathon and is not being presented as newly created work. Some of its foundation code may be reused. Any reused code must be identified, checked for permission to reuse and publish, and disclosed with a clear distinction between existing work and work created during the hackathon.

At initialization, this repository contains only this project plan; no `udao-next` application code has been imported.

## Planned Kiro workflow

Use Kiro specs to define the application, steering documents to guide implementation, and hooks for relevant checks. Actual Kiro usage and development evidence will be documented as the work is completed.

There is no runnable application yet. Setup instructions and a working demo will be added after implementation.
